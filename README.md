# Flores Amarillas

Sitio estático optimizado para celulares y listo para publicar en Vercel.

## Publicar

1. Creá un proyecto nuevo en [Vercel](https://vercel.com/new).
2. Importá esta carpeta o subila a un repositorio de GitHub y conectalo.
3. Vercel detecta `index.html` automáticamente: no hace falta configurar un comando de build.
4. Tocá **Deploy**.

El archivo `Floricienta.mp3` debe permanecer junto a `index.html`.
